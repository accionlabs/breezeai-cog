# MCP Python SDK — entry-point roles

Parser: `src/breezeai_cog/parsers/python_mcp/tools.py` (additive detector); the `@<server>.tool` reader and the `mcp.servers` fact are in `parsers/python_mcp_common.py`, shared with [`fastmcp`](fastmcp.md); the low-level reader and the `mcp.lowlevel-servers` fact are in `parsers/python_mcp/lowlevel.py` · Rules: [entry-point contract](../architecture/entry-points.md) · Tests: `tests/unit/test_roles_python_mcp.py`

A tool of a server built with the official Python SDK: its `FastMCP` (`mcp.server.fastmcp`), or its low-level `Server` (`mcp.server.lowlevel`). The fields of an `mcp_tool` record, how `params` is read and limited, and what an incremental sync does are the same for every MCP framework: [entry-point contract, MCP tools](../architecture/entry-points.md#mcp-tools).

Both packages declare a tool the same way, so one reader serves both: every rule of the [FastMCP table](fastmcp.md) for `endpoint`, `description`, `params` and the skipped parameters applies here unchanged. Only the package that built the server differs.

| Construct | Role | Record | Why |
|---|---|---|---|
| `@<server>.tool` / `@<server>.tool(name=…, description=…)` on a function, the server built with `FastMCP` imported from `mcp.server.fastmcp` | Binding | `mcp_tool`, `framework: python-mcp`, at the decorator; every other field as in the [FastMCP table](fastmcp.md) | `<server>` is a name assigned `FastMCP(…)`, a parameter annotated `FastMCP`, or a name imported from a module that assigns one; for an imported server, the file that builds it decides the framework |
| `@<server>.tool` on a server built with the standalone `fastmcp` package | None here | Recorded once, as [`fastmcp`](fastmcp.md) | Each tool is emitted once, by the package of its server |
| `types.Tool(name=…, description=…, inputSchema={…})` / `Tool(…)` returned by a function decorated `@<server>.list_tools()` — a direct element of `return [...]` or of `return ListToolsResult(tools=[...])` — on a low-level `Server` (imported from `mcp.server.lowlevel`, `mcp.server.lowlevel.server` or `mcp.server`) | Binding | `mcp_tool`, `framework: python-mcp`, at the `Tool(…)` call; `endpoint` = `name=` (a string literal); `description` = `description=` when a literal; `params` from a literal `inputSchema` dict read as a JSON schema (`properties` / `required` / `type` / `description`), anything else (`Model.model_json_schema()`, an f-string inside) → `null`; `handler` = the function decorated `@<server>.call_tool()` on the same server in the same file (it dispatches every tool), none or several → no handler; a server with more than one `list_tools` function (only the last registered answers) → no record | `<server>` is a name assigned `Server(…)` in its scope or an enclosing one, a parameter annotated `Server`, or a name imported from a module that assigns one at module level and bound by nothing else in this module (`server = wrap(server)` is no proof); `Tool` / `types` must be bound to `mcp.types` (or `mcp`) and bound by nothing else in the module |
| A list of tools built any other way in `list_tools` (a comprehension, a filter, a condition, a variable, a nested function) | None | — | Which tools it holds is not written in the code |
| A computed tool name (`name=NAME`, `name=Tools.X.value`) | None | — | The tool exists, but its name is unknown |
| `@<x>.list_tools()` on a local class named `Server` (also when the SDK's `Server` is imported and the module binds the name again: `class Server`, `from socketio import Server`, `Server = …`) or inside a function that binds `Server` itself (`from socketio import Server` in it), a name rebound in a nearer scope, a server name a function declares `global` (`nonlocal`) and binds again (`global server; server = other()`), `types.Tool` with the standard library's `types`, `Tool` / `types` imported from the SDK and bound again in the module (`import types`, `from other import Tool`, `Tool = …`, `from other import *`); LangChain `@tool` / `StructuredTool`, pydantic-ai `@agent.tool`, OpenAI Agents `@function_tool` | None | — | Not an MCP server tool |
| `@<server>.resource(…)` / `@<server>.prompt(…)` on an official-SDK FastMCP server | Binding | `mcp_resource` / `mcp_prompt`, `framework: python-mcp`, read as in the [FastMCP table](fastmcp.md) | Shared reader (`python_mcp_common.py`) |
| A low-level server's `@<server>.list_resources()` / `list_resource_templates()` function returning `[types.Resource(uri=…, name=…, description=…), …]` / `[types.ResourceTemplate(uriTemplate=…, …)]` (also `ListResourcesResult(resources=[…])` / `ListResourceTemplatesResult(resourceTemplates=[…])`) | Binding | `mcp_resource`, `framework: python-mcp`, at each `Resource(…)` call; `endpoint` = `uri=` / `uriTemplate=` (a string literal, or `AnyUrl("…")` / `FileUrl("…")` of one; else no record); `name` = `name=` when a string literal, else the URI; `params` `[]` for a `Resource` (a fixed URI), a template's simple `{variables}`; `handler` = the single `@<server>.read_resource()` function on the same server in the file (none / several → none) | Same proof as for tools; `Resource` / `ResourceTemplate` from `mcp.types` |
| `@<server>.list_prompts()` returning `[types.Prompt(name=…, description=…, arguments=[types.PromptArgument(name=…, description=…, required=…)])]` (also `ListPromptsResult(prompts=[…])`) | Binding | `mcp_prompt`, `framework: python-mcp`; `params` from the literal arguments (`required` false unless `True`; no `arguments` → `[]`; a non-literal list → `null`); `handler` = the single `@<server>.get_prompt()` function | As above |
| A client: `ClientSession` from `mcp` (`async with ClientSession(r, w) as s`, `s = ClientSession(…)` or `(s := ClientSession(…))`, or a parameter annotated `ClientSession`) → `s.call_tool("x", …)` / `s.read_resource("uri")` (or `AnyUrl("uri")`) / `s.get_prompt("x", …)` (also `name=` / `uri=`) | Outbound | `mcp_call`, `framework: python-mcp`, on the call's own statement; no file framework | The nearest binding of the name must be the client; `aiohttp.ClientSession`, an agent framework's `MCPServerStdio.call_tool`, LlamaIndex `BasicMCPClient`, a rebound name (also a `def` / `class` / `import … as` of that name in the function) → none; `global` / `nonlocal` send a function's rebinding to the module / the enclosing function. Detector `python-mcp-client` (`parsers/python_mcp/clients.py`) |

Resource / prompt fields and `params`: [entry-point contract, MCP resources and prompts](../architecture/entry-points.md#mcp-resources-and-prompts); client calls: [MCP client calls](../architecture/entry-points.md#mcp-client-calls).
