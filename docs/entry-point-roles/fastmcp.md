# FastMCP — entry-point roles

Parser: `src/breezeai_cog/parsers/python_fastmcp/tools.py` (additive detector); the `@<server>.tool` reader and the `mcp.servers` fact are in `parsers/python_mcp_common.py`, shared with [`python-mcp`](python-mcp.md) · Rules: [entry-point contract](../architecture/entry-points.md) · Tests: `tests/unit/test_roles_fastmcp.py`

A tool of a server built with the standalone `fastmcp` package. The fields of an `mcp_tool` record, how `params` is read and limited, and what an incremental sync does are the same for every MCP framework: [entry-point contract, MCP tools](../architecture/entry-points.md#mcp-tools).

A tool is recorded only when the object it is registered on is **proven an MCP server** and its name is a literal. Agent frameworks use the same word (`@agent.tool`), and a local class named `FastMCP` is not the package's — those are left alone.

| Construct | Role | Record | Why |
|---|---|---|---|
| `@<server>.tool` / `@<server>.tool(name=…, description=…)` on a function, the server built with the standalone `fastmcp` package (FastMCP 2/3) | Binding | `mcp_tool`, `framework: fastmcp`, at the decorator; `endpoint` = `name=` / first positional string, else the function name; `description` = `description=`, else the docstring; `params` from the signature (`Annotated[T, Field(description=…)]` / `Annotated[T, "…"]` — only `Annotated`'s own metadata, not strings inside `T`; `= Field(…)`; a param without one takes its entry in the docstring's Google `Args:` (`Arguments:`, `Parameters:`, `Params:`, `Keyword Args:`, …) / NumPy `Parameters` + `----------` / Sphinx `:param [type] name:` section, read even when `description=` replaces the docstring — the first style with an entry wins (a Google section of only `limit / page: …` still stops the search), a later entry of a name replaces an earlier one, only an exact param name matches (`limit / page: …` matches neither; NumPy `x, y : int` documents both), Sphinx `:param` / `:parameter` / `:arg` / `:argument` / `:keyword`; each entry cut at 1024 characters and docstring descriptions added only while the tool's whole `params` JSON stays within 15 KB, `Field` descriptions included (the backend drops all params over 16 KB); this follows FastMCP 4 (griffe) for the common Google / NumPy / Sphinx forms (cog is slightly more lenient on Google headers), while on FastMCP ≤3 and the official SDK it is cog-side enrichment the served schema does not carry; defaults, including `Field(default=…)` inside `Annotated`; `Field(...)` / `Field(default=...)` is required); `self`, `*args`, `**kwargs`, `Context` (also `Context | None`, `Optional[Context]`) and the names in a literal `exclude_args=[…]` skipped (a non-literal `exclude_args` → `params` null); `enabled=False` → no record | `<server>` is a name assigned `FastMCP(…)`, a parameter annotated `FastMCP`, or a name imported from a module that assigns one — `FastMCP` itself imported from `fastmcp`; for an imported server, the file that builds it decides the framework |
| `@<server>.tool` on a server built with the official SDK (`from mcp.server.fastmcp import FastMCP`) | None here | Recorded once, as [`python-mcp`](python-mcp.md) | Each tool is emitted once, by the package of its server |
| A computed tool name (`name=NAME`) | None | — | The tool exists, but its name is unknown |
| `@agent.tool` (pydantic-ai), LangChain `StructuredTool`, `.tool` on any other object, a local class named `FastMCP` | None | — | Not an MCP server tool |
| `@<server>.resource("uri", name=…, description=…)` (or `uri=`) on the same proven server | Binding | `mcp_resource`, `framework: fastmcp`, at the decorator; `endpoint` = the URI, a literal (else no record); `description` = `description=`, else the docstring; `params` = the template's simple `{variables}` (`[]` for a fixed URI, `null` with an RFC 6570 operator); `handler` = the function; `enabled=False` → no record | As for a tool |
| `@<server>.prompt` / `@<server>.prompt(name=…, description=…)` (or a first positional name) | Binding | `mcp_prompt`, `framework: fastmcp`; `endpoint` = `name=`, else the function name; `description` and `params` read as for a tool (the SDK builds the arguments from the signature) | As for a tool |
| A client: `async with Client(…) as c` (`fastmcp.Client`) → `c.call_tool("x")` / `c.read_resource("uri")` / `c.get_prompt("x")` | Outbound | `mcp_call`, `framework: fastmcp`, on the call's own statement; `method` `TOOL` / `RESOURCE` / `PROMPT`; `endpoint` = the literal; no file framework | `Client` imported from `fastmcp` / `fastmcp.client`; detector `python-mcp-client` (`parsers/python_mcp/clients.py`) |
| `@agent.resource` / `@click.prompt` / a local `FastMCP` class; an agent framework's MCP server object (`MCPServerStdio.call_tool`), LangChain `MultiServerMCPClient.get_tools()` | None | — | Not an MCP server / client |

Resource / prompt fields and `params`: [entry-point contract, MCP resources and prompts](../architecture/entry-points.md#mcp-resources-and-prompts); client calls: [MCP client calls](../architecture/entry-points.md#mcp-client-calls).
