# mcp-go — entry-point roles

Parser: `src/breezeai_cog/parsers/go_mcpgo/tools.py` (additive detector) · Rules: [entry-point contract](../architecture/entry-points.md) · Tests: `tests/unit/test_roles_mcp_go.py`

A tool a Go MCP server declares with `github.com/mark3labs/mcp-go`. The fields of an `mcp_tool` record, how `params` is read and limited, and what an incremental sync does are the same for every MCP framework: [entry-point contract, MCP tools](../architecture/entry-points.md#mcp-tools).

| Construct | Role | Record | Why |
|---|---|---|---|
| `mcp.NewTool(name, mcp.WithDescription(…), mcp.WithString(…, mcp.Required(), mcp.Description(…), mcp.Default…(…)), …)` (`mark3labs/mcp-go`) | Binding | `mcp_tool`, `framework: mcp-go`, at `NewTool`; `params` from the `With<Type>` options, `null` (unknown) when an option is not one of them nor a known non-parameter option (description, title, annotations, output schema); `handler` = the second argument of the `AddTool`, or the `Handler` of the `server.ServerTool{Tool: …, Handler: …}` literal (also an element of `[]server.ServerTool{…}`), that registers it: directly, or through its variable — the registration of it after the assignment in the same function and before the variable is reassigned (several disagreeing → null); a package-level variable: the one registration from a function that does not declare its own variable of that name, only when nothing reassigns it (otherwise null); `mcp.NewTypedToolHandler(fn)` / `server.NewTypedToolHandler(fn)` → `fn` | The `mcp` package of mcp-go, under any import name |
| A computed tool name (`mcp.NewTool(name, …)` with a variable) | None | — | The tool exists, but its name is unknown |
| `mcp.NewResource("uri", "name", mcp.WithResourceDescription("…"), …)` / `mcp.NewResourceTemplate("tpl", "name", mcp.WithTemplateDescription("…"))` | Binding | `mcp_resource`, `framework: mcp-go`, at the constructor; `endpoint` = the URI / template literal; `name` = the second argument when a literal, else the URI; `params` `[]` for `NewResource` (a fixed URI), a template's simple `{variables}`; handler from the `AddResource` / `AddResourceTemplate` call or `server.ServerResource{Resource: …, Handler: …}` / `ServerResourceTemplate{Template: …}` literal, followed as for a tool | Same package proof as for tools |
| `mcp.NewPrompt("name", mcp.WithPromptDescription("…"), mcp.WithArgument("a", mcp.ArgumentDescription("…"), mcp.RequiredArgument()))` | Binding | `mcp_prompt`; `params` one per `WithArgument`; an option the reader does not know → `null`; handler from `AddPrompt` / `server.ServerPrompt{Prompt: …}` | |
| A client: `c, err := client.New…Client(…)` (mcp-go's `client` package; or a parameter typed `*client.Client`) → `c.CallTool(ctx, req)` / `ReadResource` / `GetPrompt` | Outbound | `mcp_call`, `framework: mcp-go`; `endpoint` = `Params.Name` (`URI`) of an inline `mcp.CallToolRequest{Params: mcp.CallToolParams{Name: "x"}}`, or of a request variable declared once whose only `req.Params.Name = "x"` write sets it and that is passed to this one call; no file framework | The receiver's only binding in its function must be the client. Detector `go-mcpgo-client` (`parsers/go_mcpgo/clients.py`) |

Resource / prompt fields and `params`: [entry-point contract, MCP resources and prompts](../architecture/entry-points.md#mcp-resources-and-prompts); client calls: [MCP client calls](../architecture/entry-points.md#mcp-client-calls).

The official Go SDK is in the [go-mcp table](go-mcp.md).
