# MCP server tools — entry-point roles

Parsers (additive detectors): `src/breezeai_cog/parsers/python_mcp/` (tools + the `mcp.servers` fact), `typescript_mcp/`, `java_mcp/` (tools + the `spring-ai.mcp-server` fact), `csharp_mcp/`, `go_mcp/`; shared fields in `parsers/mcp_common.py` · Rules: [entry-point contract](../architecture/entry-points.md) · Tests: `tests/unit/test_roles_mcp.py`

An MCP tool is an entry point an AI client calls by name (BREEZEAI-1457). Every tool becomes one `mcp_tool` statement: `method: TOOL`, `endpoint` = the name clients call (after any rename), `framework` = the SDK, `handler` / `handlerLine` = the function that runs it, `description`, and `params` = `[{name, type, required, default, description}]` read from the input schema.

A tool is recorded only when the object it is registered on is **proven an MCP server** and its name is a literal. Agent frameworks and chat clients use the same words (`@agent.tool`, Spring AI `@Tool`, `.tool(…)`), and a local class named `FastMCP` is not the SDK's — those are left alone.

| Construct | Role | Record | Why |
|---|---|---|---|
| Python `@<server>.tool` / `@<server>.tool(name=…, description=…)` on a function (FastMCP 2/3, `mcp.server.fastmcp`) | Binding | `mcp_tool`, `framework: fastmcp` (the standalone package) or `mcp-python` (the official SDK), decided by the file that builds the server, at the decorator; `endpoint` = `name=` / first positional string, else the function name; `description` = `description=`, else the docstring; `params` from the signature (`Annotated[T, Field(description=…)]`, `= Field(…)`, defaults); `self`, `*args`, `**kwargs`, `Context` skipped | `<server>` is a name assigned `FastMCP(…)`, a parameter annotated `FastMCP`, or a name imported from a module that assigns one — `FastMCP` itself imported from `fastmcp` / `mcp.server.fastmcp` |
| TypeScript / JavaScript `<server>.tool(name, [description], [zodShape], [annotations], callback)` (`@modelcontextprotocol/sdk`) | Binding | `mcp_tool`, `framework: mcp-sdk-ts`, at the call; an object is the params shape only when its values are zod chains (`.describe`, `.optional`, `.default`, `z.enum([…])`) | `<server>` is assigned `new McpServer(…)` (a variable, `this.x`, or a class field) or typed `McpServer`; a wrapped callback (`withErrors(async (a) => …)`) counts, with the innermost callback as handler |
| TypeScript `<server>.registerTool(name, {description, inputSchema}, callback)` | Binding | as above; `inputSchema` = a zod raw shape, `z.object({…})`, or a JSON-schema literal (`properties` / `required`) | |
| Java `@McpTool(name, description)` with `@McpToolParam(description, required)` (Spring AI MCP annotations) | Binding | `mcp_tool`, `framework: spring-ai-mcp`, at the annotation; `endpoint` = `name`, else the method name | MCP annotations by definition |
| Java `@Tool(name, description)` with `@ToolParam` (Spring AI) | Binding — **only** in a module whose build file (`pom.xml`, `build.gradle[.kts]` in the file's folder or an ancestor) declares a Spring AI MCP server starter | as above; `ToolContext` and MCP exchange / context parameters skipped | Without an MCP server, `@Tool` is a chat-client function |
| C# `[McpServerTool(Name = …)]` with `[Description(…)]` (`ModelContextProtocol`) | Binding | `mcp_tool`, `framework: mcp-csharp`, at the attribute; `endpoint` = `Name`, else **empty** (the SDK derives it, version-dependent); `description` = `[Description]`, else the XML `<summary>`; a parameter is optional only with a default; `CancellationToken`, `IMcpServer` / `McpServer`, `RequestContext<…>`, `IProgress<…>`, `IServiceProvider`, `[FromServices]` skipped | The SDK's own attribute |
| Go `mcp.NewTool(name, mcp.WithDescription(…), mcp.WithString(…, mcp.Required(), mcp.Description(…), mcp.Default…(…)), …)` (`mark3labs/mcp-go`) | Binding | `mcp_tool`, `framework: mcp-go`, at `NewTool`; `handler` = the second argument of the `AddTool` that registers it: directly, or through its variable — the first `AddTool` of it after the assignment in the same function (a package-level variable: the first anywhere) | The `mcp` package of mcp-go, under any import name |
| A computed tool name (`name=NAME`, `Name = Const`) | None | — | The tool exists, but its name is unknown |
| `@agent.tool` (pydantic-ai), LangChain `StructuredTool`, Spring AI `@Tool` without an MCP server, `.tool(…)` on any other object | None | — | Not an MCP server tool |

Not covered yet (follow-up): Kotlin, the low-level APIs (Python `Server.list_tools`, TypeScript `setRequestHandler(ListToolsRequestSchema, …)`, Java `McpServerFeatures.SyncToolSpecification`), the official Go SDK, `mcp_resource` / `mcp_prompt`, and MCP **client** calls.
