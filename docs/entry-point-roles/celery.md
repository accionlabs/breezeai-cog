# Celery — entry-point roles

Parser: `src/breezeai_cog/parsers/python_celery/tasks.py` (additive detector), `python_celery/task_names.py` (task names, a registered fact) · Rules: [entry-point contract](../architecture/entry-points.md) · Tests: `tests/unit/test_roles_celery.py`

A task is addressed by its name. `name=` gives it; otherwise Celery's default `<module>.<function>` is used **only when the code confirms it**: the name is written as a literal somewhere (a beat entry, `send_task("…")`, `signature("…")`), or the module is in Celery's task-module configuration (`autodiscover_tasks(["proj"])` → `proj.tasks`, `Celery(include=[…])`, `include` / `imports`). Otherwise the name is empty — it depends on how the worker imports the file, which the code does not show.

| Construct | Role | Record | Why |
|---|---|---|---|
| `@shared_task` / `@app.task` (with or without arguments) on a function; `app` is a Celery app — `Celery(…)` at module level of this file or of the file it is imported from, or `celery.current_app`. `@scheduler.task` and any other `.task` is not Celery, even in a project that uses it | Binding | `eventbus_consumer`, `framework: celery`, `method: MESSAGE`, `endpoint` = the task's name (see above), `handler` = the function, at the decorator (`nodeType: decorator`) | A worker runs it when a message for that name arrives |
| `class Report(Task)` with `Task` imported from celery, registered with `app.register_task(Report())` (or `(Report)`) on a Celery app, in its file or one that imports it | Binding | `eventbus_consumer` as above, at the class (`nodeType: class_definition`); `endpoint` = its `name = "…"`, or `<module>.<Class>` when the code confirms it; `handler` = `run` | A worker runs `run` when a message for that name arrives |
| A `Task` subclass never registered, registered on something that is not a Celery app, or whose base is not celery's `Task` (a project base class is not followed) | None | — | Not known to be a Celery task |
| A `beat_schedule` entry `{"task": "…", "schedule": …}`: a pair of a dict assigned to `app.conf.beat_schedule` / `CELERY_BEAT_SCHEDULE`, passed as `beat_schedule=` or to `beat_schedule.update({…})` (`nodeType: pair`); `beat_schedule.update(name={…})` (`keyword_argument`); `beat_schedule["name"] = {…}` (`assignment`) | Binding | `timer`, `PERIODIC`, `endpoint` = the schedule, `handler` = the task the name leads to (`run` for a class task) | A second trigger of the task: the schedule |
| `sender.add_periodic_task(schedule, task.s(…))` | Binding | as a beat entry, at the call (`nodeType: call`); `handler` = the task referenced | A second trigger of the task |
| Schedule | — | `crontab(…)` → cron expression (`minute hour day-of-month month day-of-week`, unset `*`); seconds (`30.0`) or `timedelta(…)` → milliseconds; `solar(…)`, a variable → empty | |
| `task.delay(…)` / `task.apply_async(…)` (a task of this file, or imported — aliases followed) | Outbound | `eventbus_send`, `endpoint` = the task's name as its consumer writes it (empty when unknown) | Sends a message to the task |
| `app.send_task("name")` on a Celery app (as above); a user class's own `send_task` method is not a send | Outbound | `eventbus_send`, `endpoint` = the literal (empty for a variable) | Sends by name |
| A signature — `task.s(…)` / `.si(…)` / `.signature(…)`, celery's `signature("name")` — that is run: `.delay()` / `.apply_async()` on it; inside a celery `chain` / `group` / `chord` or a `\|` expression that is called or `.delay()` / `.apply_async()`-ed (a chord's body too); passed as `link=` to `apply_async` | Outbound | `eventbus_send`, one per signature: at the `.delay` / `.apply_async` call for a signature run directly, at the signature inside a canvas or `link=`; `endpoint` = the task's name, or the literal of `signature("name")` | Sends a message to each task |
| A signature or canvas stored in a variable and run later, a signature called directly (`task.s()()` runs in-process), `itertools.chain` | None | — | Not followed / not a send |
| `Celery(…)`, `autodiscover_tasks`, `app.conf` settings | Wiring / None | — | Configuration; feeds the task names |
| `.delay()` on something not known to be a task | None | — | Not known to be Celery |
